Setup checklist

  1. Create a free Supabase project.
  2. Run supabase-schema.sql in SQL Editor.
  3. Create your admin user under Authentication → Users.
  4. Add that user UUID to admin_users using the SQL comment at the bottom of the schema.
  5. Paste the Project URL + anon/publishable key above and test the connection.

What this will give you

  • Online storage for portfolio content.
  • Real admin authentication can replace the current local demo login.
  • Content can be edited from the dashboard and persist across devices after deployment.
  • The Media Library now uses the existing portfolio-media Supabase Storage bucket for central file management.
