V42 — Contact Enquiry Modal
Built directly from working V41.

Changes:
- Send an Enquiry opens a centered modal instead of scrolling to an inline form.
- Contact form is hidden until opened.
- Name, email, enquiry category, subject, and message are all required.
- Subject is now mandatory; category has an explicit placeholder.
- Client-side validation prevents incomplete submissions.
- Successful submission shows a dedicated success popup state inside the modal.
- Escape, backdrop, and close button dismiss the modal.
- Existing Supabase submission and optional email notification flow preserved.
